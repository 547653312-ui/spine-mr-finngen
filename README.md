# Immune traits and spine-specific osteomyelitis: a two-sample Mendelian randomization study

Analysis code, harmonised instrument tables and figures for the manuscript
*"No robust causal effect of genetically predicted immune traits on
spine-specific osteomyelitis: a two-sample Mendelian randomization study"*.

The pipeline is written in pure Python and needs **no authentication tokens**:
exposure data are pulled from the public EBI GWAS Catalog Summary Statistics
REST API and outcome data are read directly from the FinnGen R11 public release
by remote BGZF random access.

---

## Quick start

```bash
git clone https://github.com/547653312-ui/spine-mr-finngen.git
cd spine-mr-finngen
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

python analysis/00_fetch_metadata.py   # resolve EFO / FinnGen trait metadata
python analysis/mr_pipeline.py         # primary two-sample MR (45 pairs)
python analysis/supplementary.py       # power, Steiger, cross-phenotype meta
python analysis/supplementary_network.py   # drug-target (cis-pQTL) MR
python analysis/mvmr_finngen.py        # multivariable MR (BMI / T2D / smoking)
python analysis/make_main_figures.py   # Figures 1-4 (300 dpi)
python manuscript/build_manuscript.py  # assemble manuscript .docx / .tex
```

Tested with Python 3.13 on Windows 11. Total runtime ≈ 40 min, dominated by
remote GWAS retrieval; intermediate results are cached under `data/cache/`
(git-ignored, regenerated automatically).

## Data sources

| Role | Source | Access |
|------|--------|--------|
| Exposures (11 immune / cytokine traits) | EBI GWAS Catalog Summary Statistics REST API, GRCh38 | https://www.ebi.ac.uk/gwas/summary-statistics |
| Outcomes (5 osteomyelitis phenotypes) | FinnGen R11 public release | https://finngen.gitbook.io/documentation/ |
| Confounders (BMI, T2D, smoking) | FinnGen R11 public release | as above |

No individual-level or controlled-access data are used. Trait identifiers
(EFO codes and FinnGen phenotype codes) are listed in `data/manifest_exposures.tsv`
and `data/manifest_outcomes.tsv`.

## Reproducibility notes

* `data/cache/` and `data/raw/` are deliberately excluded from version control.
  They are regenerated by the fetch steps; deleting them costs runtime, not results.
* FinnGen chromosome fields must be passed as integer-like strings
  (`str(int(float(chrom)))`); a float chromosome (`"1.0"`) silently misses the
  tabix index.
* `FinnGenSumstats` objects are created per query. Re-using one object across
  many random-access lookups on multi-gigabyte files can corrupt its block cache.
