# STROBE-MR Reporting Checklist

*Per Skrivankova et al., JAMA 2021 (DOI: 10.1001/jama.2021.18236) and the accompanying BMJ explanation and elaboration (DOI: 10.1136/bmj.n2233).*

| # | Item | Section / Location in this manuscript |
|---|------|----------------------------------------|
| 1 | Indicate the study's design with a commonly used term in the title or the abstract | **Title & Abstract** — "two-sample Mendelian randomization study" |
| 2 | Provide in the abstract an informative and balanced summary of what was done and what was found | **Abstract** |
| 3 | Explain the scientific background and rationale for the investigation being reported | **Introduction** — "Clinical and pathophysiological background"; "The causality problem" |
| 4 | State specific objectives, including any pre-specified hypotheses | **Introduction** — "Objectives and hypotheses" |
| 5 | Present key elements of study design early in the paper | **Introduction** + **Methods** (Study design) |
| 6 | Describe the setting, locations, and relevant dates, including periods of recruitment, exposure, follow-up, and data collection | **Methods** — Data sources (exposures, outcomes); Supplementary Table S1 |
| 7 | Give the eligibility criteria, and the sources and methods of selection of participants | **Methods** — exposure/outcome data sources; instrument selection |
| 8 | Clearly define all outcomes, exposures, predictors, potential confounders, and effect modifiers | **Methods** — Data sources (full trait tables); instrument selection |
| 9 | For each variable of interest, give sources of data and details of methods of assessment (measurement). Describe comparability of assessment methods if there is more than one group | **Methods** — Data sources |
| 10 | Describe how the study size was arrived at (i.e., all available GWAS summary statistics for the relevant traits, or a justification for any sub-sampling) | **Methods** — Data sources; instrument selection |
| 11 | Explain how quantitative variables were handled in the analyses (e.g., categorisations, transformations); if applicable, describe which groupings were chosen and why | **Methods** — instrument selection (F>10), palindromic SNP handling |
| 12 | (a) Describe all statistical methods, including those used to control for confounding; (b) describe any methods used to examine subgroups and interactions; (c) explain how missing data were addressed; (d) if applicable, describe analytical methods taking account of sampling strategy; (e) describe any sensitivity analyses | **Methods** — MR estimation; sensitivity analyses; power and meta-analysis; drug-target MR; MVMR |
| 13 | (a) Describe any efforts to address potential sources of bias; (b) if applicable, describe the nature and direction of any pleiotropy assessment | **Methods** — sensitivity analyses (Cochran Q, MR-Egger intercept, weighted median/mode, Steiger directionality, leave-one-out) |
| 14 | Explain how the quantitative outcome and exposure measures were obtained and how the instruments were identified (e.g., genome-wide significant variants, polygenic risk scores, expression quantitative trait loci) | **Methods** — Instrument selection (P<5×10⁻⁸, F>10, ±500 kb distance pruning, palindromic MAF<0.42) |
| 15 | For Mendelian randomization: (a) provide a clear description of how the genetic variants were selected as instruments for the exposure; (b) report the variant inclusion/exclusion criteria and any proxy variants used; (c) report the number of variants used and the F-statistic for each; (d) report assumptions made and methods used to assess the assumptions | **Methods** — Instrument selection; **Results** — instrument characteristics (Table 1); **Limitations** — assumptions |
| 16 | For Mendelian randomization, describe the main analysis method and the methods used to assess its robustness | **Methods** — MR estimation (IVW, MR-Egger, weighted median/mode); sensitivity analyses |
| 17 | (a) Give characteristics of study participants (e.g., demographic, clinical, social); for cohort studies give follow-up time for each group; (b) give characteristics of the exposure and outcome GWAS used (sample size, ancestry, platform) | **Methods** — Data sources (full trait tables with n and ancestry); Supplementary Table S1 |
| 18 | For Mendelian randomization: (a) report the number of SNPs used as instruments per exposure; (b) report the F-statistic and mean F for each exposure; (c) report the proportion of variance in the exposure explained by the instruments (R²) where available | **Results** — Instrument characteristics; Supplementary Table S2 |
| 19 | For each exposure–outcome pair, report the causal estimate (point estimate and confidence interval) and the P-value | **Results** — Primary IVW estimates; **Supplementary Table S2** |
| 20 | (a) Report the results of any sensitivity analysis conducted; (b) for heterogeneity assessment, report Cochran Q and I²; for directional pleiotropy, report MR-Egger intercept; for directionality, report Steiger test P-value | **Results** — Sensitivity analyses; **Supplementary Tables S2, S4** |
| 21 | (a) Report any correction for multiple testing applied and the threshold used; (b) report the number of independent exposure–outcome tests | **Methods** — Sensitivity analyses (FDR + Bonferroni, 55 tests); **Results** — note application |
| 22 | Summarise key results with reference to study objectives | **Discussion** — Summary of findings |
| 23 | Discuss limitations of the study, taking into account sources of potential bias or imprecision, and discuss the direction and magnitude of any potential bias | **Limitations** (full dedicated section) |
| 24 | Give a cautious overall interpretation of results considering objectives, limitations, multiplicity of analyses, results from similar studies, and other relevant evidence | **Discussion** — Interpretation; Positioning against prior work; Translational implications |
| 25 | Discuss the generalisability (external validity) of the study results | **Discussion** — Translational implications; **Limitations** — European (FinnGen) generalisability |
| 26 | Give the source of funding and the role of the funders for the present study and, if applicable, for the original study on which the present article is based | **Acknowledgements** (to be added at acceptance) |
| 27 | Provide information on data and code availability (where to access the data and code used in the analyses) | **Data availability** statement; **Code availability** statement (GitHub + Zenodo DOI placeholders) |

> *A signed copy of this checklist with each item checked and the corresponding manuscript page/section filled in will be submitted as a Supplementary file alongside the manuscript.*
